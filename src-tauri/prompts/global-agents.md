# Universal workspace

This directory is the working directory of OMP Workspace's "Universal" space (sessions with no project).

- Keep this directory clean. Do NOT write temporary files, scratch scripts, or intermediate outputs here.
- Put temporary work in the system temp directory (e.g. `$TMPDIR`); do not delete it proactively, the OS cleans it up.
- Write deliverables the user asked for to a location the user names (or ask); never default to this directory.
- Do not list or read files here unless the user asks.
