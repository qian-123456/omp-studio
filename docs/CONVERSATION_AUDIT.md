## 已完成的修复

### 桌面辅助对话

- 首问先取得完整的继承历史基线，再登记自己的临时消息，再发起提问；早到的运行开始事件不再把首问误排入暂存队列。
- 仅对可识别的本会话首问边界恢复可见性；父历史和其他隐藏上下文保持隔离。嵌套辅助对话、历史搜索使用同一边界。
- 创建期间单飞、切页重挂、原父会话定位、关闭页签后的迟到完成、失败回滚均保持正确目标；草稿、引用和图片不被旧请求覆盖。
- 首问交接只消费实际提交的图片。已经发送的图片不会再次进入追问，新添加的图片及其标记仍保留。
- 永久消费者测试覆盖文本、引用、图片、嵌套首问，以及真实输入组件到第二次发送的附件内容；未通过绕过初始化逻辑来使测试通过。

### 桌面主对话、历史与显示

- 用户／工具消息结束、无关命令完成或拒绝，不再清除当前助手输出；同一输入的开始与结束不会消耗两次临时消息。
- 已明确结束的自动重试，不论成功、失败或取消都归入历史，保留错误详情；不顺带清除其他运行的正文、工具或请求。该修复覆盖没有新运行结束事件的本地继续失败。
- 转录和局部记录请求使用代际校验，防止删除后被旧响应复活及同标识重新打开时的旧响应覆盖；已回答弹窗不被旧快照恢复。
- 停止后的非空回答继续显示。历史接管不再受固定十秒期限影响，也不能以较短的持久化前缀吞掉已观察的回答后缀。
- 接管只采用原始消息时间，不将统计显示的回退时间当成持久化身份。同批结束与历史到达不会重复显示答案。
- 缓存或待发内容不再遮住读取错误和重试入口。编辑／重发保留图片、文件负载；不可取得的图片保留明确占位，不伪造内容或路径。
- 修复长代码围栏、围栏字符及关闭长度识别；回归比较实际 Markdown 渲染的代码块，而非只把字符串重新拼接。

### 草稿、附件与队列

- 提交只消费当次快照。等待期间新增的附件、修改过的批注、清空后重新输入的同样文字，都不再被旧请求成功回调吞掉；失败合并和临时页到真实会话交接保持所有权。
- 暂存发送按精确版本消费；异步删除确认按稳定目标定位，不再因列表变化删除错误消息。
- 删除所有正文及图片标记后，即使仍有结构化图片，也明确拒绝发送并保留队列、图片和错误提示；不调用发送接口、不伪报成功。恢复正文或既有图片标记后，沿原生图片发送路径处理。没有新增空正文图片确认协议。
- 合并发送预留后、图片转换完成前，保留只读的附件显示快照，直到真实临时消息接替，避免缩略图暂时消失；顺序和预留策略未改变。
