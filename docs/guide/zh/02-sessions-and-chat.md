## 空间与会话管理

### 空间体系

左侧栏顶部展示当前所在的**空间**。点击名称可快速在 **切换模式** 菜单中选择：

| 空间 | 定位与适用场景 |
| --- | --- |
| **Code** | 专为代码研发打造，支持按仓库、Git 工作树和分支层级管理会话 |
| **Work** | 适用于日常工作任务、文档起草与日常事务跟踪 |
| **Study** | 针对技术探索、论文阅读与知识梳理 |
| **Research** | 针对深度调研与复杂方案推导 |
| **Universal** | 无需关联本地项目目录的通用自由对话空间 |

各空间之间的数据与会话完全独立，切换空间时会话列表自动隔离。当其他空间有智能体正在后台运算时，空间菜单项右侧会出现动态提示点。

### 会话分组与层级结构

- **项目目录分组**：在侧栏项目区点击 `+`（添加工作区目录）关联本地文件夹。项目分组支持折叠收起。
- **工作树智能聚类**：在 Code 空间下，开启 **设置 ▸ 会话 ▸ 按工作树区分会话** 后，同一仓库内属于不同分支或 Git Worktree 的会话将自动归拢在对应的工作树分组下，多任务并行修改一目了然。
- **Universal 自由分组**：通用空间无需代码仓库，你可以使用 **新建分组** 整理对话，并在会话右键菜单中使用 **移到分组**。
- **置顶与标星**：常用会话可随时置顶，固定在列表顶部。

### 会话生命周期与状态标志

每条会话旁均配有直观的状态标记，鼠标悬停可查看详情：

| 状态 | 列表标记 | 含义与操作建议 |
| --- | --- | --- |
| **运行中** | 旋转加载图标 | 智能体正在思考或执行工具操作 |
| **待回复** | 蓝色「待回复」标签 | 智能体发起了审批请求（写入文件/执行命令）或向你提问 |
| **待验收** | 行末蓝色圆点 | 智能体已完成当前轮次工作，等待你审阅确认；右键可「验收并归档」 |
| **空闲** | 无标记 | 当前无正在进行的任务，处于随时待命状态 |
| **异常/报错** | 红色实心圆点 | 因网络或工具错误非正常退出，右键可进行会话体检或诊断 |
| **已中断** | 橙红警告标 | 智能体进程被意外终止，右键点击「恢复会话」即可从断点续接 |
| **已挂起（休眠）** | 浅灰休眠标 | 闲置超过设定阈值后自动休眠以释放系统内存；发消息时即刻毫秒级唤醒 |
| **外部接管** | 终端指示图标 | 由原生终端 `omp` 运行的会话；右键可选择「接管会话」转为桌面端托管 |

> [!NOTE]
> 自动休眠时间可在 **设置 ▸ 会话 ▸ 闲置多久后休眠（分钟）** 中自由调整，默认 15 分钟，休眠会话完整保留所有上下文。

### 快捷检索与键盘流操作

- **全文检索（`⌘F`）**：在侧栏搜索框输入关键词，支持空格分隔多词复合匹配。检索范围覆盖：会话标题、分支名称、工作树目录、模型标识及最近一条助手回复摘要。
- **会话操作菜单**：右键点击会话（或按行末菜单按钮），支持：重命名、置顶/取消置顶、归档会话、在访达中定位、诊断此会话、重启会话、导出等。
- **纯键盘导航流**：焦点置于列表时，按 `↑` / `↓` 移动选区并平滑加载会话；按 `←` / `→` 折叠或展开当前分组；按 `Delete` 快速归档；按 `Shift+Delete` 永久删除。

## 开启新会话

### 标准模式与项目绑定

点击左侧栏 **新建会话** 或按快捷键 `⌘N`。
系统会自动在中间区域打开一个崭新的输入界面。若当前已有选中的项目，新会话自动绑定该项目；空白草稿未输入任何内容离开时会自动清理，不会在列表残留无效死会话。
新会话的输入框上方也会显示项目和 Git 分支；查看这些信息不会启动后台会话。切换或新建分支时才会准备执行该操作所需的后台会话。草稿中的分组标签仅用于显示。

### 独立 Git 工作树（Worktree）并行模式

当你想让智能体开发一个全新需求，但不想污染当前正在编辑的代码分支时：
1. 点击项目分组右侧的 `+` 按钮，选择 **在独立工作树创建**；
2. 在弹出面板中确认基础分支（如 `main`）、新分支前缀（如 `feat/`）与新目录名；
3. 点击创建后，系统将在 `<项目>/.worktrees/<名称>` 目录下自动拉出全新分支并建立独立工作树；
4. 多个智能体可以同时在各自的工作树中拉代码、跑测试、提交变更，互不阻塞！

## 智能输入框与消息发送

输入框不仅是打字框，更是多任务调度的中枢。

![输入框功能一览](../images/sessions-and-chat-composer.png)

### 沉浸式自然打字（Type-to-focus）
应用内置智能打字捕获：在浏览消息、翻看文档或审阅 Diff 时，只要当前焦点未处于其他输入框、终端或模态弹窗内，直接按下键盘字符，焦点将自动瞬时转入输入框，彻底告别频繁的鼠标点击定位。同时内置输入法（IME）防抖，组词期间不会误触快捷键。
使用拼音输入法时，用于确认候选文字的那次 `Enter` 不会发送消息；确认后再按一次 `Enter` 才发送（默认发送配置）。

### 并发发送策略与临时切换

当智能体正在思考或长耗时运行工具时，如果又有了新想法，输入框提供了三种精巧的处理策略（在 **设置 ▸ 会话 ▸ 发送方式** 中配置默认值）：

1. **引导（Steer，默认推荐）**：消息会作为实时的前置补充，立即注入智能体当前的回合中，指导其修正路径，无需等待全部跑完；
2. **排队（Queue）**：消息进入排队队列，等智能体把当前任务彻底完成后，自动接续发出；
3. **打断后发送（Interrupt）**：立即强制终止当前回合，并立即带着新指令重新开始。

> [!TIP]
> **单次快捷切换**：按住 `⌥` 键发送（如 `⌥Enter`）可以对当前单条消息反转策略（例如将引导临时切换为排队），无需修改全局配置。

### 排队队列管理
已排队的消息会以半透明气泡形式暂存于消息流末尾。点击输入框右侧的 **排队 N** 标签可展开管理面板，支持：调整消息发送先后顺序、合并多条排队消息合并发送、或一键移出队列。

### 添加菜单与增强模式

点击输入框左侧的 `+`（添加）可开启高级工作模式：

- **规划模式（Plan 模式）**：勾选后智能体会先输出方案；仅开启模式不会自动展开空面板。新计划完成后，右侧才自动打开 **计划** 面板供你审阅，再批准执行；重新打开已有计划的会话不会强制展开面板。命令 `/plan` 只会开启规划模式，不会关闭；关闭请点击输入框上的规划标签（X）或 + 菜单中的规划项，应用内的开关是静默的，不会在对话中产生消息。命令发出后输入框中的规划标签会清除。
- **目标模式（Goal）**：设定长期追求的验收目标。输入框上方将出现目标进度卡，即使历经多次上下文压缩，智能体也不会偏离核心目标；支持 `/goal <描述>` 配置。
- **草图画布（Sketch）**：内置手绘矢量白板，支持画笔、箭头、矩形、文本与配色，画完直接一键插入输入框作为视觉参考。
- **多媒体附件与代码引用**：支持直接从访达粘贴或拖入图片（PNG/JPG/SVG）、日志文件、代码片段，支持一键载入访达当前选中的文件。

### `@` 快速引用与 `/` 斜杠命令

- **输入 `@` 文件引用**：输入 `@` 并键入文件名关键字，可在当前工作目录中快速模糊搜索文件，自动插入路径引用。
- **输入 `/` 触发命令菜单**：
  - **会话流转**：`/new`（新会话）、`/fork`（派生当前对话）、`/btw`（开启侧聊）、`/compact`（压缩上下文）、`/shake`（快速抖掉冗余工具结果）；
  - **模型调度**：`/model`（快速选模）、`/thinking`（设置思考预算）、`/advisor`（呼叫顾问模型协同）；
  - **状态与分析**：`/status`（查看系统状态）、`/context`（查看上下文构成）、`/stats`（查看吞吐量与耗时）；
  - **环境与安全**：`/mcp`（MCP 状态）、`/login`（登录供应商）、`/settings`（直达设置）。

### 模型选择与真实思考等级

底部工具栏显示当前模型。点击可打开双栏供应商模型选择器（左侧供应商分类，右侧模型列表，支持拼音与模糊检索）。
模型名右侧附带思考等级（如 `off`, `low`, `medium`, `high`）。所列出的档位严格根据所选模型的官方真实能力动态解析，绝不呈现硬编码的不支持选项。

## 划选批注与精准引用

在阅读消息、查阅右侧文件、审阅 Git Diff 或终端输出时，只需**用鼠标划选任意一段文字**，即可唤出浮动批注栏：

- **写批注（`Enter` 确认）**：写下对该段代码或回复的具体要求，支持选择将批注附加到 **主对话** 还是 **辅助对话**；
- **批注暂存区**：批注将作为结构化卡片整齐悬浮于输入框上方，支持查看原文出处、随时修改或删除，点击发送时会自动拼接为带有精准行号与上下文的结构化提示词。

## 辅助对话（Side Chat）

辅助对话是主会话的轻量级“沙盒分身”，非常适合做临时方案推导、原理咨询或辅助测试，而完全不破坏主会话干净的上下文。

- **快速开启**：在右侧面板点击 `+` ▸ **新辅助对话**，或直接在输入框输入 `/btw 你的疑问`。
- **上下文继承**：辅助对话自动获得主会话当前的全部历史与记忆；
- **多层嵌套**：支持从辅助对话中继续开下级辅助对话（最多 3 层），按 `⌘[` 随时返回上一级；
- **一键整理回传**：在辅助对话得出结论后，点击右上角 **回传给父会话**，系统将自动提炼精炼结论并放入主会话输入框，确认后即可发送。

## 执行追踪与审批确认

### 透明的执行细节展示

智能体的每一次操作在对话区均以标准工具卡形式呈现：
- 动态显示：正在读取 → 已读取、正在搜索 → 已找到、正在编辑 → 已保存；
- 多步自动化任务会自动收起为折叠步骤条，避免长输出刷屏；
- 模型思考内容以收纳块展示，可开启 **思考时显示最新两行** 查看动态心流；
- 命令行调用提供 **复制命令** 与 **查看完整输出**。

### 审批请求与键盘交互

当安全级别需要介入时，对话流中会呈现明确的审批卡：
- 按键盘 `y`：**仅本次执行**（安全受控）；
- 点击 **本会话始终允许**：本会话生命周期内不再反复询问；
- 点击 **永久加入白名单**：全局信任；
- 按键盘 `n`：**拒绝执行**，智能体将立即改变策略。

智能体主动向你提问时（Ask），输入框会自动转换为选项面板：按数字键快速选择，`Enter` 提交，亦可自由填写自定义回答。

### Git 对话检查点与一键撤回

在 **设置 ▸ 会话 ▸ 对话检查点** 开启自动存档后：
- 应用在智能体每一轮行动前自动通过 Git 进行项目快照留底；
- 如果智能体改坏了代码或思路跑偏，在回复下方点击 **撤回这一轮**，即可将本轮所有文件的改动一键物理还原，彻底规避代码丢失风险！

## 上下文用量与深度精简

输入框底部配备环形上下文水位指示盘。点击可展开用量仪表盘：

- **细分维度拆解**：清晰掌握已用 Token 中各个组成部分的占比（系统提示词、内置工具定义、MCP 服务、Skills 技能描述、规则文件、对话历史）；
- **查看系统提示词构成**：一键跳转分析每次发给模型的底层 Prompt，支持让 AI 诊断并给出精简方案；
- **手动压缩（`/compact`）**：调用总结模型压缩对话上下文，保留关键结论并释放空间；
- **快速抖动（`/shake`）**：零模型开销，纯粹丢弃过往工具调用的冗长返回内容，极速腾出上下文。

## 会话分享与导出

点击主界面顶部工具栏的 **分享与导出** 按钮：

| 导出方式 | 特性与适用场景 |
| --- | --- |
| **选择消息生成图片** | 自由勾选重要消息轮次，渲染为精致的长截图（支持复制或保存为 PNG） |
| **创建加密分享链接** | 将会话加密上传至云端只读阅读页，自动对已知 API 密钥与敏感信息执行物理脱敏 |
| **复制为 Markdown** | 一键将整场对话以标准 Markdown 源码拷贝至系统剪贴板 |
| **导出为独立 HTML** | 导出包含现代样式的离线单文件 HTML，脱离网络亦可随处翻阅 |
| **手机扫码同屏查看** | 在同一局域网下生成实时 Web 端访问码，手机端即刻同步浏览与回复 |
