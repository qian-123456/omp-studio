## 创建周期定时任务

定时任务允许智能体在指定的时间点或周期性循环中自动执行任务（如：每日清晨汇总前一日 Git 提交、每周五扫描依赖库安全漏洞、定期分析代码坏味道等），并将处理结果同步至收件箱。

点击左侧栏的 **定时任务** 即可打开任务管理中心。

### 常用任务模板快速启用
在任务列表为空时，可直接选用内置的典型工程模板：
- **晨会工作准备**：每天 09:00 自动总结团队昨日提交并整理今日关注点；
- **依赖安全巡检**：每个工作日 10:00 自动检查项目依赖更新与已知 CVE 漏洞；
- **周末待办盘点**：每周五 17:00 梳理当前未关闭的 TODO 与临时注释。

### 详细配置项指南
点击 **新建任务** 进入编辑界面：

| 配置字段 | 说明与建议 |
| --- | --- |
| **任务标题** | 简明标识任务用途；留空时将自动使用提示词第一行作为标题 |
| **执行周期** | 支持 **每小时**、**每天**、**每工作日**、**每周**、**每月**，或 **自定义间隔**（最少 5 分钟），亦支持单次执行（指定未来时间） |
| **重复截止** | 可选 **从不**、**指定截止日期** 或 **重复 N 次后终止** |
| **执行指令（Prompt）** | 派发给智能体的详细任务描述，支持拖入参考图片作为多模态输入 |
| **项目工作区** | 任务运行的目标目录；可选已有项目、通用全局工作区或自定义路径 |
| **审批访问模式** | **完全访问**（全自动通过，适合无人值守例行巡检）；**写入需审批**（只读自动通过，写文件需确认）；**每次询问**（所有写操作等待人工批准） |
| **模型与思考深度** | 默认继承全局默认模型，亦可指定性价比更高的专用轻量模型 |

### 高级选项：专属 Git Worktree 隔离
在定时任务的 **高级选项** 中，强烈建议开启 **在独立 Git Worktree 中运行**：
- 启用后，定时任务每次触发都会自动在一个隔离的分支与工作树中拉起执行，绝不污染你当前正在本地编辑的代码工作区！
- **每次运行新建会话**：推荐开启，确保每次例行巡检都有干净独立的上下文。

> [!WARNING]
> 当审批模式低于「完全访问」时，若定时任务在半夜或离开电脑时触发且需要审批，任务会自动挂起并在收件箱中等待，直至你确认后继续。

### 查看历次运行日志
切换至定时任务的 **历史** 标签，可完整查阅历次执行的状态（运行中、成功、失败、已跳过）及消耗时间。点击任意历史记录，可直接在主工作台打开该次运行创建的真实会话。

## 智能收件箱管理

收件箱是工作台中所有需要人工介入事项的统一指挥中心。点击左侧栏顶部的铃铛图标（**收件箱**）即可打开，图标上的小徽标会实时展示当前待处理总数。

### 智能待办自动汇流
收件箱完全无需手动录入待办。系统会自动侦测并归集以下五大类事件：

| 分类标签 | 汇集条件与触发场景 |
| --- | --- |
| **待审批** | 智能体即将执行危险工具（如写入关键文件、运行 Shell 脚本），等待人工放行 |
| **提问** | 智能体在方案分支上向你发起询问（Ask），等待你做出选择或补充信息 |
| **报错** | 智能体在执行过程中遇到网络故障、环境缺失或未捕获的严重异常 |
| **中断** | 因断电、强制退出或进程崩溃而意外停滞的会话，支持一键恢复续跑 |
| **未读** | 智能体已顺利完成整轮工作，等待你审阅验收的会话 |

### 极速处理流
- **纯键盘盲操**：进入收件箱后，按键盘 `j` / `k`（或 `↓` / `↑`）快速切换条目，按 `Enter` 瞬间跳转至目标会话；
- **一键全部已读**：点击右上角 **全部已读**，即可将所有已完成和报错的未读提示一键消警；
- **自动移出机制**：在 **设置 ▸ 会话 ▸ 收件箱** 中，可设定闲置超时时间（默认 48 小时），超时未变动的非阻塞条目会自动移出收件箱，保持通知列表清爽。

## 想法收集箱（Backlog）

开发过程中灵感往往转瞬即逝，或者在查阅代码时突然发现一处潜在 Bug。想法收集箱是一个常驻的“外挂脑皮层”，方便随手记下，稍后集中派发给智能体。

点击窗口中间顶栏右侧的灯泡图标（**想法收集**）展开面板。

### 随时捕获想法
- **双类型标记**：记录时可快速区分为 **想法（Feature/Idea）** 或 **缺陷（Bug）**；
- **附带上下文**：勾选 **附带当前会话**，系统会自动关联当前正在讨论的上下文与代码位置；
- **图片与截图支持**：直接粘贴剪贴板中的报错截图或设计示意图。

### 全局快捷键随时唤出
无论你当前处于 IDE、浏览器还是办公聊天软件中，按下系统全局快捷键（默认 `⌘⇧I`），屏幕正中央会立即弹出轻巧的 **记到收集箱** 浮窗。记完后按 `⌘Enter` 提交，浮窗自动隐去，你的工作流完全不被打断。

> [!TIP]
> 全局快速记录快捷键可在 **设置 ▸ 快捷键 ▸ 全局** 中自定义设置。

### 批量整理与智能派发
在收集箱中，条目按 **待处理**、**运行中**、**待验收** 和 **已结束** 清晰分类：
1. **填入输入框**：将选中的想法文本直接追加至当前会话的草稿框；
2. **派发给智能体（Dispatch）**：
   - 勾选一条或多条想法，点击 **派发**；
   - 自由选择 **追加至已有会话** 或 **为该需求开启全新独立会话**；
   - 确认后智能体立即根据收集箱中的内容开始编码！
3. **软删除与恢复**：误删的条目会进入 **废纸篓**，保留 7 天，期间可随时完整撤回与恢复。

## 技能与扩展能力概览

点击左侧栏的 **Skills 管理**，可以快速审阅当前工作台可用的原生智能体能力库：
- **全局技能与项目级技能**：自动索引 `~/.omp/agent/skills/` 与项目本地 `.omp/skills/`；
- **调用状态一目了然**：统计每个技能近期是否活跃，及时发现存在描述过长或不可读问题的技能；
- **一键使用**：在技能详情抽屉中点击 **在当前会话中使用**，即可将对应命令注入输入框。
