## 常见问题排查

### 0. 打开应用提示「"omp-workspace"已损坏，无法打开。你应该将它移到废纸篓」
- **原因**：由于本开源项目未购买苹果每年昂贵的商业开发者认证证书，macOS Gatekeeper 安全防护机制会自动将从互联网下载的应用打上隔离标签（Quarantine），并误报“文件已损坏”。
- **解决方式（任选其一）**：
  1. **终端命令一键解除（最推荐）**：打开 Mac「终端（Terminal）」，执行以下命令即可正常打开：
     ```bash
     xattr -cr /Applications/omp-workspace.app
     ```
  2. **右键打开**：在访达「应用程序」中，按住键盘 `Control` 键点击 `omp-workspace.app` 图标，在右键菜单中点击「打开」，在弹出的确认窗口中点击「打开」；
  3. **系统设置放行**：前往 Mac「系统设置 ▸ 隐私与安全性」，滑到底部会看到“已阻止使用 omp-workspace”，点击旁边的「仍要打开」。

### 1. 提示「未找到 omp」，或新会话启动失败
- **原因**：桌面工作台默认在系统的标准 `PATH` 中调用 `omp` 命令行程序。如果你的 `omp` 安装在特定路径（例如 Homebrew 非标准目录、NVM 目录或 Python 虚拟环境），应用可能无法自动寻路。
- **解决方式**：
  1. 在系统终端中运行 `which omp`，获取其绝对路径（如 `/usr/local/bin/omp` 或 `~/.cargo/bin/omp`）；
  2. 打开工作台 **设置 ▸ 高级 ▸ omp 程序位置**，填入该绝对路径；
  3. 前往 **设置 ▸ 版本与更新** 确认已正常识别到 omp 版本。

### 2. 终端里直接运行的 omp 会话没有出现在列表中
- **原因**：终端命令行的动态事件未向工作台守护模块广播。
- **解决方式**：
  - 打开 **设置 ▸ 高级 ▸ 外部终端联动**，点击 **安装扩展**；
  - 该操作会将轻量监听扩展写入 `~/.omp/agent/extensions/`。之后你在任何外部终端运行的会话，都会以 **外部** 标记实时同步显示在工作台左侧列表中。右键点击该会话可随时选择 **接管会话**。

### 3. 会话提示「已中断」
- **原因**：通常由于系统休眠、终端关闭、电脑断电或底层进程被系统意外终止。
- **解决方式**：右键点击该会话，选择 **恢复会话**；或直接进入会话点击底部的 **恢复中断的回合**，系统将向智能体发送断点续跑信号。

### 4. 为什么键盘打字没有自动进入输入框？
- **原因**：为了防止打字与你的正常操作发生冲突，自动打字捕获（Type-to-focus）在以下场景下会主动让出键盘所有权：
  1. 当前已有其他输入框（如搜索框、文档源码编辑器）拥有焦点；
  2. 屏幕上有模态对话框、设置弹窗或下拉菜单展开；
  3. 正在内置终端中操作 Shell。
- **解决方式**：按下 `Esc` 键退出当前弹窗，或点击消息流空白处，再次打字即可瞬间进入输入框。

### 5. 上下文快满了，请求变慢或报错怎么办？
- **解决方式**：
  1. **一键压缩**：在输入框输入 `/compact` 并发送，由智能体总结提炼前序对话并释放上下文；
  2. **轻量抖动**：输入 `/shake` 并发送，瞬间物理丢弃之前庞大的工具调用输出结果，零模型耗费腾出空间；
  3. **检查提示词构成**：点击上下文水位环中的 **查看系统提示词构成**，检查是否有冗余的规则文件或过长技能描述，让 AI 协助精简。

### 6. 开发模式（`pnpm tauri dev`）下窗口偶发一片空白？
- **原因**：在源码开发模式下，当多个文件在被并发编辑且存在相互依赖尚未写入时，Vite 的热重载机制可能触发全局整页刷新并停留在白屏态。
- **解决方式**：在项目根目录下执行 `touch index.html`，强制 Vite 重新触发一次根渲染，窗口即刻恢复。

### 7. 提示「无法读取主密钥」？
- **原因**：工作台的供应商加密库依赖于主密钥文件 `~/.omp-workspace/env/.master.key`。
- **解决方式**：检查该文件是否存在以及当前用户是否拥有读写权限；如果曾手工移动过用户主目录，请确保权限为 `600`。

## 数据位置与目录结构

工作台秉持数据本地化与透明化原则，所有关键数据均保存在本地目录中：

| 本地路径 | 存储内容与用途说明 |
| --- | --- |
| `~/.omp-workspace/app.db` | 本地 SQLite 核心数据库（存储会话元信息、定时任务、想法收集箱、设置状态等） |
| `~/.omp-workspace/env/keys.env` | 由 macOS 钥匙串高强度加密的供应商 API 密钥密文文件 |
| `~/.omp-workspace/env/.master.key` | 本机加密主密钥文件（严格本地受控） |
| `~/.omp-workspace/global/` | Universal 通用空间对话所依附的全局工作目录 |
| `~/.omp-workspace/images/` | 会话中粘贴、拖拽或草图生成的本地图片缓存（超过 30 天无引用的图片会自动清理） |
| `~/.omp-workspace/privacy/` | 本地脱敏隐私库的配置文件 |
| `~/.omp/agent/sessions/` | OMP 智能体引擎的原生会话历史文件（桌面端直接读取并展现） |
| `~/.omp/agent/agents/` | 自定义子代理（Sub-agents）的定义 Markdown 模板目录 |
| `<项目目录>/.worktrees/` | 由工作台拉起的各独立 Git 工作树实体文件夹 |

> [!TIP]
> 换新电脑时，只需前往 **设置 ▸ 高级 ▸ 数据与备份** 点击 **导出设置**，并在新电脑上点击 **导入设置** 即可一键平滑迁移全部偏好。
