## 设置分类全景架构

点击侧边栏底部的齿轮图标 **设置**（或在输入框中运行 `/settings`、按快捷键 `⌘,`），设置将在中间主区域展开。

工作台设置分为七大分类，涵盖本应用配置与 OMP 底层引擎配置：

| 分类分组 | 包含页面与核心定位 |
| --- | --- |
| **常规** | **通用**（新会话默认行为、Git 交付模式、审批模式）、**存储空间**（缓存与磁盘占用）、**外观**（主题与排版密度）、**通知**（系统提醒与免打扰）、**隐私**（密钥打码与脱敏） |
| **模型** | **模型与供应商**（API 密钥、OAuth 订阅、配额用量）、**模型角色**（主力/轻量/深度等角色分配）、**思考与采样**（思考深度与参数）、**辅助模型**（顾问、预探与视觉辅助）、**备用模型与重试**（自动回退链）、**上下文窗口**（模型窗口限制与自动压缩） |
| **会话** | **会话**（休眠与工作树策略）、**收件箱**（待办自动汇集规则）、**会话体检**（体检触发模型与频率）、**规则文件**（长期 AGENTS.md 规范与输出校验）、**系统提示词构成**（System Prompt 占比可视化与 AI 精简建议） |
| **Agent 能力** | **工具**（工具白名单与权限）、**文件读写**（读取/编辑策略与 LSP 诊断）、**命令行**（Shell 运行模式）、**子代理**（自定义子代理定义与创建）、**记忆**（长期记忆文件与跨会话状态）、**技能与命令**（Skills 路径与加载） |
| **连接** | **手机访问**（局域网配对、Cloudflare Tunnel 隧道、IPv6 直连与 DDNS）、**MCP 服务器**（接入外部工具协议）、**插件**（已安装插件与原生扩展）、**联网搜索**（Web 搜索服务配置） |
| **高级** | **高级**（omp 可执行程序路径、终端联动扩展、配置文件直接定位、数据备份与一键重置） |
| **帮助** | **使用教程**（即本教程，功能详解与技巧速查）、**版本与更新**（检查应用与 omp 引擎最新版本并热更新） |

> [!TIP]
> 在设置页顶部搜索框输入关键词（按 `⌘F` 聚焦），可在全站所有配置项中秒级模糊检索。

## 配置模型供应商与密钥

进入 **设置 ▸ 模型与供应商**。支持 **接口与密钥**（API Key 按量计费）与 **订阅与配额**（OAuth 订阅账号）。

### 添加 API 供应商
1. 点击 **添加供应商**；
2. 在 **从预设开始** 中选择（内置主流预设：Anthropic、OpenAI、DeepSeek、Google Gemini、Moonshot Kimi、OpenRouter、SiliconFlow、Groq、Mistral、xAI、Ollama，或选择 **自定义 OpenAI 兼容**）；
3. 填入名称、环境变量名及 API Key；展开 **进阶设置** 可自定义协议标准（OpenAI Compatible / Responses / Anthropic / Gemini / Ollama）、默认上下文窗口及输出上限；
4. 点击 **获取模型列表** 从接口实时拉取可用模型，或手动填入模型 ID；
5. 点击 **保存并加密密钥**。

> [!NOTE]
> **钥匙串级硬件加密**：工作台采用 macOS 系统钥匙串的主密钥对 API Key 进行 AES-256-GCM 本地加密，密文保存在 `~/.omp-workspace/env/keys.env`，明文仅在向接口发送请求时短暂驻留在内存中，绝不写入普通文件或日志。

### OAuth 订阅账号与配额看板
- 点击 **OAuth 登录**：通过浏览器完成官方授权流程，凭据直接托管于系统安全凭证库；
- 切换至 **订阅与配额** 标签页：可视化展现各供应商订阅账号的使用比例、重置周期与剩余重置券，实时监控余量。

## 核心概念辨析：模型角色 vs 自定义子代理

许多用户容易混淆“模型角色”与“子代理”，请牢记两者的本质区别：

| 维度 | 模型角色（Model Roles） | 自定义子代理（Sub-agent Definitions） |
| --- | --- | --- |
| **核心本质** | 模型的**别名与用途映射**（Alias） | 具备独立 Prompt、专属模型和工具权限的**独立智能体定义** |
| **配置入口** | **设置 ▸ 模型角色** (`RolesSection`) | **设置 ▸ 子代理** (`AgentDefsPanel`) |
| **存储位置** | `~/.omp/agent/config.yml` (`modelRoles.*`) | `~/.omp/agent/agents/<名称>.md` |
| **典型代表** | `default` (主力), `smol` (轻量), `slow` (深度推理) | `task` (通用子任务), `scout` (快速代码侦察), 自定义专家 |
| **调用方式** | 在配置中以 `@角色名` 链式引用 | 在对话中由主智能体调度，或由用户指定分派 |

## 模型角色分配

在 **设置 ▸ 模型角色** 中，你可以决定不同职责的后台任务分别由哪款模型来承担：

- **主力模型 (`default`)**：承担主要对话逻辑、代码生成与主流程决策；
- **快速模型 (`smol`)**：处理轻量分类、简短判断，兼顾极速响应与低资费；
- **深度模型 (`slow`)**：负责架构设计、疑难 Bug 深度排查，具备高推理能力；
- **视觉模型 (`vision`)**：理解用户传入的图片、UI 截图与设计草图；
- **专用角色**：规划设计 (`plan`)、提交信息生成 (`commit`)、记忆梳理 (`memory`)、顾问分析 (`advisor`) 等。

> [!TIP]
> 每一行均支持选择 **专属模型** 或 **复用角色模型**（写入 `@default` 等），一旦主力模型更换，复用该角色的所有下游任务自动跟随升级。

## 创建与管理自定义子代理

进入 **设置 ▸ 子代理**。这里展示所有可由主智能体派发的专业子代理（包含内置的 `task`、`scout`、`reviewer` 以及你自定义的专属子代理）。

### 新建子代理
点击 **添加子代理**，弹出创建表单：
1. **子代理代号（Name）**：小写英文字符与连字符（如 `security-auditor` 或 `doc-writer`）；
2. **职责描述（Description）**：告诉主智能体“在什么场景下应该把任务派发给你”（例如：“负责审查代码中的潜在安全漏洞与注入风险”）；
3. **分配专属模型**：为该子代理指定最适宜的模型；
4. **工具权限白名单**：精确勾选该子代理可以调用的工具（例如限制只能使用 `read` 和 `grep` 只读工具，严禁 `write` 或 `bash`）；
5. **系统提示词（System Prompt Body）**：定义子代理的角色准则、输出契约与工作规范。

### “让 AI 帮我写” 一键生成
不确定如何编写高质量的子代理 Markdown？点击表单顶部的 **让 AI 帮我写** 按钮，描述你希望构建的专家角色（例如：“帮我写一个专门负责审查 React 19 渲染性能与重渲染问题的子代理”），系统将自动为你生成规范的 Prompt 与推荐工具权限，一键填入表单！

## 模型批量替换与模板自动切换

当某个模型服务调整、下线或你想统一将某个模型升级时，无需手动逐项翻找修改：

### 批量替换模型（Model Replace）
在 **模型角色** 页面点击 **批量替换**：
1. **选择来源模型**：扫描并列出全局配置、所有已添加项目、回退链以及定时任务中的所有引用位置；
2. **选择目标模型**：指定要换成的新模型并选择思考等级；
3. **精确预览变动**：直观对比每一处的 旧 → 新 变动，遇到冲突时自动合并去重，允许单独取消勾选某一项；
4. **一键应用与运行中会话热切换**：写入配置后，可直接勾选将当前正在运行的会话即刻迁移到新模型；
5. **安全撤销机制**：系统保留最近 10 次替换历史，支持随时一键完全撤销。

### 角色模板与配额自动降级
在 **模板与自动切换** 卡片中：
- **方案模板**：将一套完整的角色模型分配保存为一个方案（如“极致性能方案”、“低成本省钱方案”）；
- **按额度自动切换规则**：设定触发规则（如：当某供应商本周配额消耗达到 90% 时，自动将当前项目切换为“省钱方案”；当配额恢复时自动切回）。

## 备用模型与重试回退

进入 **设置 ▸ 备用模型与重试**。确保在模型突发限流、服务中断或额度超限时，你的开发任务不被打断。

- **回退链配置**：为每个角色（如 `default`）排定多级备选名单（如：`Claude 3.5 Sonnet` → `DeepSeek V3` → `GPT-4o`）；
- **同账号故障轮换**：额度不足时优先轮换同一供应商的备用账号，再回退到其他供应商模型；
- **防死循环机制**：内置最大连续重试次数与超时保护，防止无限循环消耗资费。

## 规则文件、记忆与系统提示词

### 规则文件（AGENTS.md）
进入 **设置 ▸ 规则文件**。长期规则决定了智能体的工作习惯与工程规范：
- **全局长期规则**：存放在 `~/.omp/agent/AGENTS.md`，每次对话自动注入；
- **项目级规则**：位于项目根目录下的 `AGENTS.md`，用于定义该项目的架构契约、技术栈禁忌与代码风格；
- **输出实时检查规则**：配置智能体在每一次输出时强制自检的核心准则。

### 记忆文件管理（Memory）
进入 **设置 ▸ 记忆**。智能体在多轮迭代中积累的可复用经验存储于记忆文件中：
- 浏览与检索跨会话积累的长期记忆条目；
- 对已过时、不准确的项目假设进行手动修正或一键清理。

### 系统提示词构成（Prompt Composition）
进入 **设置 ▸ 系统提示词构成**：
- **可视成分拆解**：清晰查看每一次向模型发起请求时，系统提示词是由哪些部分构成的（内置基础提示词、工具协议定义、MCP 工具描述、Skills 技能说明、AGENTS 规则文件等）以及各占用了多少 Token；
- **AI 瘦身建议**：点击 **让 AI 分析并建议精简**，分析是否存在冗余规则或过长描述，大幅降低首字延迟与开销。

## 接入 MCP 服务器与插件

### MCP 服务器（Model Context Protocol）
进入 **设置 ▸ MCP 服务器**。为智能体扩展无限外部能力：
- 支持本地命令行服务（`stdio`，如通过 `npx` 调起各类服务）、远程 `HTTP` 接口及 `SSE` 推送协议；
- **项目级与全局隔离**：支持将特定 MCP 仅绑定在当前项目，避免无关项目加载大量无用工具导致上下文膨胀；
- **环境变量加密**：支持安全填入第三方 Token（如 GitHub、Sentry 凭据）。

### 插件与扩展模块
进入 **设置 ▸ 插件**。集中管理随应用附带或手动安装的原生插件（如代码可视化组件 Visualize、外部脚本扩展等），支持一键启用、禁用与更新。

## 隐私库与自动脱敏

进入 **设置 ▸ 隐私**。彻底解决在对话或代码调试中不慎将 API Key、数据库密码、生产 Token 泄露给大模型的隐患：

- **添加隐私项**：将敏感字符串加入隐私库并设置代号（如“测试库密码”）；
- **动态占位符**：发给 AI 的所有消息与上下文会被自动替换为不含语义的占位符（如 `⟦密码_a1b2⟧`）；
- **本地安全还原**：占位符仅在智能体于本机真正执行 Shell 命令或工具的那一刹那在内存中还原为真实值；
- **防误伤机制**：针对较短的字符串可开启“仅还原手动标记处”，避免误伤正常代码。

## 配置备份、恢复与更新

- **设置导出与导入**：在 **设置 ▸ 高级** 中，可一键将本应用的所有工作台偏好设置导出为 JSON 备份文件，换机时一键覆盖导入；
- **恢复出厂设置**：遇到配置混乱时可一键清空重置；
- **版本更新**：在 **设置 ▸ 版本与更新** 中，可同时检查桌面工作台本体与底层 OMP 引擎的更新。OMP 引擎更新无需重启客户端，新轮次自动无缝承接。
