## 掌握 Token 用量与开销分布

在右侧面板打开 **Token 用量** 标签页（快捷键 `⌘J`），面板提供 **本对话** 与 **全局洞察** 两种视图。

### 1. 本对话用量分析
选中当前会话后，面板清晰呈现：
- **上下文水位计**：当前会话已占用的 Token 数与当前模型上下文上限的百分比，临近上限时自动告警；
- **五大开销维度分布条**：
  - **Tool Calls**：工具调用的输入参数与返回结果占用；
  - **Skills 注入**：已加载技能的描述信息占用；
  - **System Prompt**：基础系统提示词与 AGENTS 规则文件占用；
  - **MCP 服务**：外部 MCP 协议工具清单占用；
  - **思考与回复**：模型的内在推理链与最终文本输出。
- **逐项下钻与定位**：点击任意分类卡片，可展开每一次具体工具调用的消耗明细；点击 **定位** 按钮，主对话流即刻平滑滚动至对应轮次；
- **子代理省流统计**：如果会话派发了子代理，顶部可切换查看主对话与各子代理的独立开销，右上角直观展示通过子代理隔离技术为你节省的上下文总量。

### 2. 全局洞察与历史账单
切换至 **全局洞察** 标签页：
- 聚合统计全部会话的 Token 消耗、累计预估成本与会话总数；
- 按照 **最高消耗优先**、**最多问题优先** 或 **最新活动优先** 筛选排序；
- 顶部的 **长期共性问题 Top 3** 会根据多次会话体检结果，自动提炼你在需求表述或指令下达中的常见思维盲区。

## 会话深度体检（Session Doctor）

当一场复杂的长对话变得迟缓、出现频繁返工或消耗远超预期时，无需人工从头翻看漫长记录。**会话体检** 会由一个独立的轻量模型回看整场对话，精准开具“体检诊断单”。

### 四大体检方向
在 **Token 用量 ▸ 🩺 会话体检** 中选择针对性方向：

| 体检方向 | 核心排查目标与解决痛点 |
| --- | --- |
| **🪙 省钱瘦身** | 揪出无意义的重复文件读取、超大工具返回、无效的试错重试与可压缩环节 |
| **🎯 提问调优** | 深度分析你的初始需求表述是否存在歧义、漏项，导致智能体思路偏航或范围蔓延 |
| **🛡️ 代码暗坑** | 检查智能体在未彻底验证的情况下做出的过度设计、破坏既有约定的改动或潜在 Bug |
| **💬 自由体检** | 针对该场对话提出你关心的任何特定问题（如：“分析第 3 轮工具调用为何失败”） |

### 骨架脱水技术与纠偏 Prompt 生成
- **隐私与轻量化脱水**：系统会自动将整场对话脱水提取为仅保留“目标、动作流、错误日志与改动文件”的精简骨架，绝不将完整历史全部回传，既保护隐私又大幅节省资费；
- **纠偏 Prompt 草稿**：体检报告不仅给出根因分析，还会直接生成一份**纠偏提示词草稿**。点击 **填入输入框** 即可立即发给智能体，一键拨乱反正！

> [!TIP]
> 前往 **设置 ▸ 会话体检**，可以为体检指定速度快、价格极低的专用模型，并可配置每日定时体检或会话闲置后自动体检。

## 诊断异常与中断会话

当某个会话报错停止或进程意外中断时：
1. 在左侧栏右键该会话，选择 **诊断此会话**；
2. 系统自动提炼报错现场与最后几轮关键日志，生成结构化的诊断上下文；
3. 选择 **由哪个 Agent 执行诊断**（可选择一个空闲的已有会话，或开启一个全新的独立诊断会话）；
4. 点击 **开始诊断**，派发的智能体将专注于该报错日志进行源码排查，避免在原出错会话中反复试错导致污染现场。

## 本地服务与端口治理

在右侧面板打开 **服务** 标签页，这里是本地开发服务器与常驻进程的“任务管理器”。

### 识别与状态监控
- 系统自动扫描本机当前监听的所有端口，并高亮标记前端开发服务器（如 Vite、Next.js、Webpack、Uvicorn 等服务）；
- 每一行清晰显示监听端口、服务进程名、`PID`、对应的工作目录，以及该服务是由哪场智能体会话拉起的；
- 点击端口地址，可直接在默认浏览器中一键打开页面。

### 时光机服务标记与残留清理
- **时光机快照服务**：带有专属的「时光机」标记，方便与正式开发环境区分；
- **残留进程一键清理**：如果某个端口对应的智能体会话已经关闭或结束，该服务会被标记为 **残留**。面板顶部会浮现 **一键清理** 横幅，点击后即可一键杀死全部孤儿进程，彻底解决“端口被占用”的困扰。

## 性能与内存真实监控

点击窗口底部状态栏的 **性能 xxx MB** 按钮，可唤出系统级性能监视面板。

### 严谨的物理内存口径
- 采用与 macOS「活动监视器」完全一致的**物理常驻内存（Footprint）**口径统计；
- 清晰拆解呈现：本应用界面进程、本窗口智能体进程、本机其他终端的 OMP 进程及空闲系统内存；
- **开发与生产区别**：在开发模式（`pnpm tauri dev`）下由于未打包的 Vite 模块热替换与 Debug 符号，数值会偏高；生产打包后经过深度优化，闲置占用极低。

## 全场景手机远程访问

出门在外、躺在沙发上，或者在会议室中，你依然可以用手机查阅长任务的运行进展，并即时批准工具调用。进入 **设置 ▸ 手机访问**。

### 1. 局域网极速配对（同一 Wi-Fi）
1. 在 **手机访问服务** 卡片点击 **启动**；
2. 点击 **生成配对二维码**；
3. 用手机微信或相机扫一扫二维码，即刻在手机浏览器中打开轻量化 Web 版工作台；
4. 手机端支持：浏览会话流、发送后续指令、一键批准/拒绝危险工具调用、查看文件与 Git 提交。

### 2. 公网隧道（离开 Wi-Fi 访问）
如果电脑在公司或家中，想在路上用手机移动蜂窝网络访问：
- **临时公网地址（基于 Cloudflare Tunnel）**：
  - 本机安装 `cloudflared`（`brew install cloudflared`）；
  - 选择 **临时公网地址** 并点击启动，系统将自动分配一个安全的专属 `trycloudflare.com` 临时域名并生成公网配对码；
  - 无需公网 IP，无需配置路由器端口映射，安全穿透 NAT！
- **固定自有域名**：支持绑定你自己在 Cloudflare 托管的域名与隧道凭据，实现长期稳定的远程访问。

### 3. IPv6 公网直连与 DDNS 自动解析
对于拥有公网 IPv6 的宽带网络：
- 启动 **直连（IPv6）** 服务，手机利用 5G/4G 的原生 IPv6 直连电脑；
- **内置 Cloudflare DDNS 动态域名解析**：开启后，当家庭宽带公网 IPv6 发生变动时，工作台会自动调用 Cloudflare API 同步更新 AAAA 解析记录，确保持续稳定连接。

### 权限快速撤销
手机丢失或公共演示结束后，随时在 **设置 ▸ 手机访问** 底部点击 **全部撤销**，所有已授权的手机将立即被踢出并失效。
