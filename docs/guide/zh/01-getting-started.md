## 了解 omp-workspace

omp-workspace 是 OMP 命令行智能体的现代化桌面外壳（基于 Tauri 2 + React 19 构建，原生沉浸体验）。它与命令行 `omp` 紧密协作而非割裂替代：

- **会话双向同步**：应用启动时自动扫描并索引 `~/.omp/agent/sessions/`。你在终端中用 `omp` 启动的会话会直接展示在左侧栏中；桌面端发起的会话也能在终端中无缝续接。
- **项目与工作树隔离**：原生支持 Git Worktree（独立工作树）。多个智能体可以在同一个仓库的不同分支或工作树下并行修改代码，互不干扰、永不踩踏。
- **可视化对话与执行追踪**：实时展示思考过程、代码 Diff、工具调用卡片与执行结果，支持自然输入法防抖打字与丰富的行间批注。
- **全套工作区辅助工具**：内置文件浏览器、Markdown 分栏文档视图、多标签交互式终端、时光机版本快照、服务端口监控与 Token 用量分析。
- **智能自动化与移动互联**：支持定时调度任务、智能待办收件箱、全局想法收集箱，以及局域网/公网安全穿透的手机端远程访问。

## 准备环境

| 检查项 | 要求说明 |
| --- | --- |
| 操作系统 | macOS（全面适配系统外观与系统钥匙串安全加密，支持访达快捷联动） |
| OMP 命令行 | 建议本机已安装 `omp` 核心引擎，且可在终端命令行中直接调用 |
| 模型凭据 | 至少一个可用的模型供应商（支持 API 密钥或 OAuth 订阅账号），见[配置模型供应商](#配置模型供应商) |
| 源码构建环境 | Node.js (>=18)、`pnpm`、Rust (Cargo) 工具链 |

应用默认通过系统环境变量中的 `omp` 命令拉起智能体进程。

> [!NOTE]
> 如果你的 `omp` 安装在非常规路径（例如自编译路径或特定的虚拟环境），请前往 **设置 ▸ 高级 ▸ omp 程序位置** 填写绝对路径。前往 **设置 ▸ 版本与更新** 可直接查看当前检测到的 omp 版本及状态。

## 安装与启动

若通过源码开发或打包：

```bash
pnpm install        # 安装前端与项目依赖
pnpm tauri dev      # 启动本地开发模式（自动构建 Rust 底层与 Vite 前端）
pnpm build:app      # 完整编译、类型检查并打包出 macOS 应用程序 (.app / .dmg)
```

> [!TIP]
> 如果想在不影响当前数据的情况下启动一个干净的调试实例，可以运行 `pnpm dev:preview`：它将使用隔离端口并将数据存入独立目录 `~/.omp-workspace-dev`。详细数据分布见[数据位置与目录结构](./07-shortcuts-and-troubleshooting.md#数据位置与目录结构)。

首次启动时，应用会自动完成初始化：
1. 在 `~/.omp-workspace/` 初始化本地配置与 SQLite 数据库；
2. 扫描加载本机历史会话与上下文；
3. 恢复上次打开的工作区与会话；未选定时停留在空间引导页。

## 认识窗口布局

工作台窗口采用符合工程直觉的四区分割布局：

![窗口布局总览：左侧栏、中间对话区、右侧面板与底部状态栏](../images/getting-started-layout.png)

### 1. 左侧栏（会话与导航）
管理所有会话与空间，按快捷键 `⌘B` 可随时展开或收起。
- **空间切换器**：顶部显示当前**空间**（如 Code、Work、Study、Research 或 Universal 通用空间）。每个空间拥有独立的项目和会话列表。
- **快捷工具入口**：顶部集成 **收件箱**（聚合待审批/报错/提问）、**搜索**（`⌘F` 全局检索会话）、**新建会话**（`⌘N`）、**定时任务** 及 **Skills 管理**。
- **项目与工作树分组**：按本地代码仓库组织会话，支持折叠展开，并可按 Git 工作树/分支聚合展示并行任务。
- **底部入口**：点击左下角齿轮打开 **设置**（或按 `⌘,`）。

### 2. 中间区域（主工作台）
核心操作视图，承载主要交互：
- **对话界面**：显示当前会话标题、状态、模型标签、消息流、工具调用详情卡、审批确认面板与输入框。
- **全屏功能视图**：打开收件箱、定时任务配置、Skills 管理、文档编辑或设置时，将平铺展开于中间区域，点击左上角返回或按 `Esc` / `⌘[` 即可切回会话。

### 3. 右侧面板（辅助工具箱）
多标签页抽屉，按快捷键 `⌘J` 展开或收起。点击标签栏末尾的 `+`（打开新标签页）可按需切换工具：
- **辅助对话（Side Chat）**：轻量级旁聊，继承主对话上下文，无需打断主线思路；
- **文件**：浏览当前工作区的文件树结构与快速检索文件；
- **Git**：查看代码 Diff、暂存与提交、工作树并行管理、主干同步与时光机历史回溯；
- **终端**：支持多个持久化 Shell 终端，可一键将输出文本作为批注发给 AI；
- **文件预览**：高亮查看代码与渲染 Markdown 文档；
- **服务与端口**：检测本机正在监听的本地开发端口，并清理残留无用进程；
- **Token 用量与体检**：分析上下文开销分布、定位浪费并提供深度会话体检。

### 4. 底部状态栏
全局监控指示器：
- 实时显示当前会话的轮数与步数、上下文缓存命中率；
- **性能监控**：显示本应用及关联进程的物理内存占用（点击可展开多进程明细）；
- **OMP 版本**：快速查看核心程序版本与更新状态；
- **当前分支与界面缩放**：显示当前工作树分支名，并提供界面字号与缩放比例调整。

## 开启第一个会话

1. **确认当前空间**：在左侧栏顶部选择所在空间。如果进行代码开发，推荐选择 **Code** 空间；日常临时对话可切到 **Universal**。
2. **选择或添加项目**：如果是首次使用，在首页点击 **选择项目目录**，选中本地代码仓库或文件夹。应用会自动关联该项目并就绪。
3. **输入需求**：光标处于输入框时，直接写下你的开发需求或指令。
4. **即打即连（Type-to-focus）**：无需反复用鼠标点击输入框——只要当前焦点不在其他文本输入框或弹窗内，直接在键盘上打字，文字便会自动送达输入框。
5. **按 `Enter` 发送**：智能体随即启动，实时流式输出思考过程、生成方案、执行工具或提出询问。

随时可以按 `⌘N` 快速开启新会话；系统会自动绑定当前项目，并在未输入任何内容离开时自动清理空白草稿。

## 配置模型供应商

智能体工作需要至少一个有效的大模型接入点。你可以通过以下方式极速配置：

- **设置面板**：打开 **设置 ▸ 模型与供应商**，点击 **添加供应商** 选择官方预设（如 Anthropic、OpenAI、DeepSeek、Gemini、OpenRouter 等）填写 API 密钥，或选择 **OAuth 登录** 使用订阅账号。
- **一键导入已有密钥**：点击 **导入 / 导出 ▸ 一键导入 OMP 供应商**，自动将终端中已有的 OMP 配置安全迁移进工作台。
- **斜杠命令快捷跳转**：在对话输入框输入 `/login` 并按回车，可直接打开供应商配置页面。

> [!TIP]
> 所有本地 API 密钥均由 macOS 系统钥匙串主密钥进行高强度加密（AES-256-GCM），明文只在向模型发起安全通信时在内存短暂驻留，绝不落盘于明文文件或日志中。
