# Statechart audit of omp-workspace

Source baseline: `7f85613a5ce16cae7ed5e0e3d24b51ecb4454658`. Generated by the statechart skill (TLA+/TLC models rendered to Mermaid statecharts). Product code was read-only during the audit.

Proposed fixed variants are MODEL-ONLY: they are checked in TLC to show what a change would do. Product code was not changed or repaired, and a green "fixed" state does not mean a fix has shipped. Findings are classified as reproduced consumer behavior (replayed against real entry points), trace-and-source-only hypotheses (a model trace plus code reading, not replayed), or design questions; the Kind column says which, and "unclassified" means the slice did not say.

- [OVERVIEW.md](OVERVIEW.md)：中文阅读入口、连续编号的问题清单、证据等级与阅读方法。
- [REPORT.md](REPORT.md): coverage, findings, limits, per-model chart links (charts themselves are in Chinese).
- [manifest.json](manifest.json): baseline, verification scope, model/file index with SHA-256.
- `<slice>/<model>/model/`: TLA+ source, `.cfg`, `.map.mjs` (and fixed/agreed models); `<slice>/<model>/chart/`: `.mmd`, `.png`, `stories.md`, `summary.json`, TLC logs.

- `<slice>/result.json` retains the complete structured handoff, including classified findings and limitations; `<slice>/evidence/` retains scrubbed replay logs and harness snapshots. These snapshots may contain archival <repo>/<scratch> placeholders; model regeneration does not rerun product replays.
- Large TLC counterexample logs are preserved losslessly as `.out.gz` after path scrubbing and secret scanning; use `gzip -dc FILE.out.gz` to read them. No counterexample log is omitted for size.

## Regenerating

Everything is regenerated in an external scratch directory; nothing is written into this tree.

```sh
export TLA2TOOLS=/path/to/tla2tools.jar   # TLC 1.7.4
export JAVA=/path/to/java                  # Java 11+
node regenerate.mjs --skill /path/to/statechart --out "$(mktemp -d)"          # rerun all models, compare with published charts
node regenerate.mjs verify                                                    # offline: file hashes, .mmd/.png pairs, forbidden paths
```

`--only slice/model` limits the run; `--skill` can also be given as `STATECHART_SKILL`. The run compares regenerated `.mmd` and `summary.json` with the published copies.
