## 1. 服务运行: 无隧道，进程0个，IPv6在线，证书域名域名甲，设置域名域名乙，已同步域名乙

Rule broken: 规则：配对页面显示的 IPv6 域名链接，必须被当前使用的证书覆盖。
Why: 运行中的 IPv6 服务不会因域名变化重新生成证书，但页面已改用新域名.
In the model, 2 different steps lead into this bug: "后台同步域名成功" and "修改 DDNS 域名". The steps below are the shortest path that TLC found.

0. Start: 服务停止: 无隧道，进程0个，IPv6关闭，设置域名域名甲，已同步无
1. 启动 IPv6 服务. Now: 服务运行: 无隧道，进程0个，IPv6在线，证书域名域名甲，设置域名域名甲，已同步无
2. 修改 DDNS 域名. Now: 服务运行: 无隧道，进程0个，IPv6在线，证书域名域名甲，设置域名域名乙，已同步无
3. 后台同步域名成功. Now: 服务运行: 无隧道，进程0个，IPv6在线，证书域名域名甲，设置域名域名乙，已同步域名乙

## 2. 服务停止: 隧道在线，进程1个，IPv6关闭，设置域名域名甲，已同步无

Rule broken: 规则：局域网服务已停止时，不应还有公网隧道地址指向它。
Why: 停止服务时只终止已登记的隧道，启动中的隧道之后仍会登记成功.
In the model, one step leads into this bug: "隧道地址就绪". The steps below are the shortest path that TLC found.

0. Start: 服务停止: 无隧道，进程0个，IPv6关闭，设置域名域名甲，已同步无
1. 启动手机服务. Now: 服务运行: 无隧道，进程0个，IPv6关闭，设置域名域名甲，已同步无
2. 点开始隧道. Now: 服务运行: 隧道启动中，进程1个，IPv6关闭，设置域名域名甲，已同步无
3. 停止手机服务. Now: 服务停止: 隧道启动中，进程1个，IPv6关闭，设置域名域名甲，已同步无
4. 隧道地址就绪. Now: 服务停止: 隧道在线，进程1个，IPv6关闭，设置域名域名甲，已同步无

## 3. 服务停止: 无隧道，进程1个，IPv6关闭，设置域名域名甲，已同步无

Rule broken: 规则：隧道已停止且没有启动在途时，不应残留 cloudflared 进程。
Why: 两次启动都成功后只登记最后一个，停止时另一个进程无人管理.
In the model, 2 different steps lead into this bug: "点停止隧道" and "停止手机服务". The steps below are the shortest path that TLC found.

0. Start: 服务停止: 无隧道，进程0个，IPv6关闭，设置域名域名甲，已同步无
1. 启动手机服务. Now: 服务运行: 无隧道，进程0个，IPv6关闭，设置域名域名甲，已同步无
2. 点开始隧道. Now: 服务运行: 隧道启动中，进程1个，IPv6关闭，设置域名域名甲，已同步无
3. 点开始隧道. Now: 服务运行: 隧道启动中，进程2个，两次启动同时进行，IPv6关闭，设置域名域名甲，已同步无
4. 隧道地址就绪. Now: 服务运行: 隧道在线，进程2个，IPv6关闭，设置域名域名甲，已同步无
5. 隧道地址就绪. Now: 服务运行: 隧道在线，进程2个，IPv6关闭，设置域名域名甲，已同步无
6. 停止手机服务. Now: 服务停止: 无隧道，进程1个，IPv6关闭，设置域名域名甲，已同步无
