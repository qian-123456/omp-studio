## 1. 显示发送失败: 输入框已恢复原文，无临时气泡，服务器已收到1条

Rule broken: 规则：输入框里恢复出未发送的文字时，服务器不应已经收到过这条消息。
Why: 手机超时后无法得知服务器已处理，仍把原文放回输入框.
In the model, one step leads into this bug: "请求超时或网络中断". The steps below are the shortest path that TLC found.

0. Start: 未发送: 输入框为空，无临时气泡，服务器已收到0条
1. 用户输入文字. Now: 未发送: 输入框有文字，无临时气泡，服务器已收到0条
2. 点发送. Now: 发送中: 输入框为空，有临时气泡，服务器已收到0条
3. 服务器收到并处理这条消息. Now: 发送中: 输入框为空，有临时气泡，服务器已收到1条（本次已到达）
4. 请求超时或网络中断. Now: 显示发送失败: 输入框已恢复原文，无临时气泡，服务器已收到1条

## 2. 发送中: 输入框为空，有临时气泡，服务器已收到2条（本次已到达）

Rule broken: 规则：同一条消息经一次点击发送，服务器最多收到一次。
Why: 超时恢复的原文被再次发送，服务器没有去重.
In the model, one step leads into this bug: "服务器收到并处理这条消息". The steps below are the shortest path that TLC found.

0. Start: 未发送: 输入框为空，无临时气泡，服务器已收到0条
1. 用户输入文字. Now: 未发送: 输入框有文字，无临时气泡，服务器已收到0条
2. 点发送. Now: 发送中: 输入框为空，有临时气泡，服务器已收到0条
3. 服务器收到并处理这条消息. Now: 发送中: 输入框为空，有临时气泡，服务器已收到1条（本次已到达）
4. 请求超时或网络中断. Now: 显示发送失败: 输入框已恢复原文，无临时气泡，服务器已收到1条
5. 点发送. Now: 发送中: 输入框为空，有临时气泡，服务器已收到1条
6. 服务器收到并处理这条消息. Now: 发送中: 输入框为空，有临时气泡，服务器已收到2条（本次已到达）
