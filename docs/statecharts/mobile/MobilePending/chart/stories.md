## 1. 屏幕显示：请求1、请求2; 服务器待处理：无，已回答：请求1、请求2、请求3，在途快照1个

Rule broken: 规则：「全部允许」只能回答用户已经在屏幕上看到过的请求。
Why: 批量允许按服务器当前的全部请求执行，包含用户还没看到的新请求.

3. 手机请求待处理列表. Now: 屏幕显示：无; 服务器待处理：请求1、请求2，已回答：无，在途快照1个
