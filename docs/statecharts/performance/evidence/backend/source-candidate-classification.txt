3. Cache miss concurrency and stale overwrite: SOURCE-ONLY CONCURRENCY HYPOTHESES.

   No concurrent backend request trace, stress test, or deliberately reordered real collector execution was performed. The normal single-effect UI inFlight guard is not proof of backend-global single flight.

5. Disputed proc_listallpids bug: REJECTED, with independent static and dynamic evidence.
   Apple official libproc.c proc_listallpids calls proc_listpids and returns numpids / sizeof(int). proc_listpids itself does not perform that division.
   Independent ctypes call to installed /usr/lib/libproc.dylib returned 576 and changed exactly 576 int slots in a 4352-byte buffer (1088 slots; sizeof(int)=4); 575 slots held positive PIDs plus one PID 0; errno=0; untouched tail retained sentinel -1.
   Therefore proc_listallpids returns PID-slot COUNT, not bytes. commands.rs:342 treating n as a count is correct. Do not divide n by 4 again or report this as a product bug.
   Evidence files: libproc-listallpids.official.txt, libproc-count-probe.json.
