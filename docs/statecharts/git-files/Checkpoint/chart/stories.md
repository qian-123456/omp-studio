## 1. 第1轮被中断且留下残留快照；文件是初始内容

Rule broken: 没有正在记录的轮次时，不会留下只有开始快照、没有条目的残留存档。
Why: 切换会话仅忘记当前轮次.
In the model, one step leads into this bug: "一轮进行中切换了会话". The steps below are the shortest path that TLC found.

0. Start: 还没有记录；文件是初始内容
1. 代理开始第1轮. Now: 第1轮进行中；文件是初始内容
2. 一轮进行中切换了会话. Now: 第1轮被中断且留下残留快照；文件是初始内容

## 2. 第1轮已撤回；文件是初始内容

Rule broken: 撤回不会悄悄覆盖用户之后做的改动。
Why: 轮内用户改动归入轮次快照.
In the model, 5 different steps lead into this bug: "点撤回第3轮", "点撤回第2轮", "点撤回第2轮（连带更新的轮次）", "点撤回第1轮", and "点撤回第1轮（连带更新的轮次）". The steps below are the shortest path that TLC found.

0. Start: 还没有记录；文件是初始内容
1. 代理开始第1轮. Now: 第1轮进行中；文件是初始内容
2. 用户自己改了文件. Now: 第1轮进行中；文件被用户改过
3. 一轮结束，记录存档. Now: 第1轮可撤回；文件被用户改过
4. 点撤回第1轮. Now: 第1轮已撤回；文件是初始内容

## 3. 第1轮撤回标记丢失，第2轮被中断且留下残留快照，第3轮可撤回；文件是第3轮写的

Rule broken: 已经撤回过的轮次，在存档清理之后仍然显示为已撤回。
Why: 旧轮次清理一并删除撤回标记.
In the model, one step leads into this bug: "一轮结束，记录存档". The steps below are the shortest path that TLC found.

0. Start: 还没有记录；文件是初始内容
1. 代理开始第1轮. Now: 第1轮进行中；文件是初始内容
2. 代理写入文件. Now: 第1轮进行中；文件是第1轮写的
3. 一轮结束，记录存档. Now: 第1轮可撤回；文件是第1轮写的
4. 代理开始第2轮. Now: 第1轮可撤回，第2轮进行中；文件是第1轮写的
5. 一轮进行中切换了会话. Now: 第1轮可撤回，第2轮被中断且留下残留快照；文件是第1轮写的
6. 点撤回第1轮. Now: 第1轮已撤回，第2轮被中断且留下残留快照；文件是初始内容
7. 代理开始第3轮. Now: 第1轮已撤回，第2轮被中断且留下残留快照，第3轮进行中；文件是初始内容
8. 代理写入文件. Now: 第1轮已撤回，第2轮被中断且留下残留快照，第3轮进行中；文件是第3轮写的
9. 一轮结束，记录存档. Now: 第1轮撤回标记丢失，第2轮被中断且留下残留快照，第3轮可撤回；文件是第3轮写的
