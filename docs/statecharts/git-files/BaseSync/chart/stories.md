## 1. 基础分支没有新提交，分支有独有提交，工作区干净，主工作区会挡住快进；界面显示失败；报错了但分支已多出合并提交

Rule broken: 同步或变基报错时，当前分支的提交历史保持同步前的样子。
Why: 并入已成功而快进失败.
In the model, one step leads into this bug: "快进基础分支".

0. Start: 基础分支有新提交，分支无独有提交，工作区干净，主工作区会挡住快进
1. 点同步，并入基础分支. Now: 基础分支没有新提交，分支有独有提交，工作区干净，主工作区会挡住快进；已并入基础分支，等待快进
2. 快进基础分支. Now: 基础分支没有新提交，分支有独有提交，工作区干净，主工作区会挡住快进；界面显示失败；报错了但分支已多出合并提交
