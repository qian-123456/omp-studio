## 1. 密钥文件正常，文件里是最新隐私块，进程没有加载最新保护，压缩被放行

Rule broken: 只要压缩被放行，正在运行的 OMP 进程启动时读到的原生保护内容就必须是最新的。
Why: 原生保护写入失败时启动的会话进程拿到了正常摘要，之后写入恢复且摘要没变，压缩被放行，但这个进程从未加载过隐私块.
In the model, one step leads into this bug: "改标签或关联会话，保护内容不变". The steps below are the shortest path that TLC found.

0. Start: 密钥文件正常，文件里是最新隐私块，没有运行中的会话进程
1. 用户手动把密钥文件改成非列表. Now: 密钥文件被手动改坏，应用还没发现，文件里没有隐私块，没有运行中的会话进程
2. 用户把密钥文件改回列表. Now: 密钥文件已改回，应用还没重写，文件里没有隐私块，没有运行中的会话进程
3. 启动一个会话进程. Now: 密钥文件已改回，应用还没重写，文件里没有隐私块，进程没有加载最新保护，压缩被放行
4. 改标签或关联会话，保护内容不变. Now: 密钥文件正常，文件里是最新隐私块，进程没有加载最新保护，压缩被放行

With the fix, step 3 (启动一个会话进程) takes you to: 密钥文件已改回，应用还没重写，文件里没有隐私块，进程没有加载最新保护，压缩被拦下.
