# omp-workspace 移动端产品需求文档 (PRD)

---

## 1. 目标与定位

为 `omp-workspace` 构建一个高性能、免安装的移动端 Web 控制台（React 19 + TypeScript + Vite + Tailwind v4），直连电脑宿主后台，在手机上流畅运行完整的 AI 编码代理工作流。

**核心解决问题**：
1. 解决手机端中文输入法打字卡顿、频繁回流掉帧问题。
2. 解决长对话与流式输出时的整段重渲染问题。
3. 补齐代理工作流：子代理监控、规划模式闭环、交互问答澄清、工具审批与图表渲染。

---

## 2. 视觉规范

移动端界面与交互的权威视觉合同见 [`docs/MOBILE_DESIGN.md`](./MOBILE_DESIGN.md)。本 PRD 定义产品能力与行为，不重复或覆盖视觉规范。该设计合同包含屏幕布局、组件、深浅色 token 与 390×844 验收条件。

---

## 3. 产品行为原则

- 用户可使用浅色或深色主题，并可跟随系统或在设置中手动选择。
- 关键信息（模型、目录、代码、报错）应完整可读；无法避免的截断必须提供查看完整内容的操作。

---

## 4. 功能规划与需求清单

### 4.1 首页 (Home)
- **中性问候**：居中展示“今天想做点什么？”，不显示任何用户名或头像昵称。
- **结构精简**：移除“聊天／任务”切换标签。
- **快速发起**：底部胶囊输入框直接键入内容发送，后台自动绑定默认目录并创建会话，平滑进入聊天页，无“会话不存在”中断。

### 4.2 左侧导航全屏抽屉 (Left Drawer)
- **顶部固定项**：发起新对话、搜索会话、定时任务。
- **视图切换**：
  - 空间切换器（代码、通用对话、学习等空间）。
  - 「按项目 / 按时间」双视图切换。
  - **按项目**：保留「项目 → 已注册工作树 → 会话」拓扑。移动端按 `workspaceId` 关联并复用已注册工作树（包括项目目录外的路径），使用所选工作树实际 `cwd` 创建会话，不以路径前缀推断归属。移动端没有创建 Git 工作树的 API；需要新工作树时，提示用户在桌面端创建并注册后再返回移动端，不得静默回退到项目主目录。
  - **按时间**：按时间轴倒序排列会话，带运行状态点。
- **底部常驻项**：
  - 收件箱（铃铛图标，带未读角标，聚合待处理事项）。
  - 订阅与配额（直达配额看板）。
  - 设置（直达系统设置）。
- **剔除内容**：移除与产品无关的库、学生、自定义、视频、笔记本等条目。

### 4.3 对话与输入区 (Chat & Composer)
- **顶栏**：菜单、当前「模型 · 思考强度」选择入口（点击呼出选择弹层）、新建对话、右侧工具菜单；外观以设计合同为准。
- **状态栏（输入框上方）**：
  - 左侧：当前工作目录（点击弹出完整路径与切换面板）。
  - 右侧：上下文用量百分比（点击呼出压缩面板，支持一键压缩上下文）。
- **加号菜单（6 项原生功能）**：
  - 文件（上传附件）、Finder 选中项（远程文件选择）、在项目中工作（切换项目目录）、目标（设置会话目标）、规划模式（切换 Plan 模式）、草图（手绘白板）。
- **右侧双操作按钮**：
  - **语音输入（麦克风）**：按住/点击录音，调用语音识别模型接口转写文字，填入输入框供编辑，不自动发送。
  - **发送 / 停止**：空闲为发送，生成中自动变为停止按钮。

### 4.4 代理工作流深度支持
- **子代理胶囊 (Subagents)**：
  - 挂载于消息区右上角，有子代理活动或记录时常驻显示进度与状态计数（运行/排队/完成/失败）。
  - 点击弹出嵌套树状概览抽屉（展示层级连线、模型、耗时）。
  - 点击单个代理进入全屏详情页（任务要求、思考折叠、工具调用参数与结果、产出、报错）。
- **规划模式闭环 (Plan Mode)**：
  - 通过加号菜单或 `/plan` 开启，输入区显示规划模式横幅。
  - 计划卡片支持复制与下载 `.md` 文件。
  - 计划底部提供明确双按钮：
    - **「执行计划」**：发送确认指令并自动退出规划模式，开始实施。
    - **「修改计划」**：保持规划模式，焦点回到输入框继续补充要求。
- **划词批注 (Text Annotation)**：
  - 长按选择 AI 或用户文本，弹出批注浮层。
  - 支持选择批注到「主对话」或「辅助对话」，选中文本作为结构化引用随批注回填至输入框。
  - 保留系统原生复制/全选菜单；不设收集箱逻辑。
- **交互澄清问答 (Questions & Choices)**：
  - Agent 发起澄清时，支持单选框、多选框及自定义文字补充。
  - 多题支持翻页计数（问题 X/Y）、跳过与失败重试。
- **工具审批 (Approvals)**：
  - 就地展示命令正文与参数，支持「单次允许」、「本会话记住」以及多工具批量审批。

### 4.5 富媒体与可视化 (Visualize & Mermaid)
- **Mermaid 流程图**：流式生成未闭合时维持纯文本代码，闭合后懒加载渲染为隔离 SVG，支持全屏双指缩放（最高 6 倍）与平移。
- **Visualize 沙箱小部件**：带安全 CSP 的独立 iframe 渲染交互式 HTML 片段，通过 postMessage 桥接主题变量与状态保存，支持全屏预览与移动端排版重叠自适应。

### 4.6 右侧工具面板集合 (Right Tools)
仅保留 5 项移动端高频工具：
1. **文件**：只读浏览工作区目录树，带面包屑导航与语法高亮预览。
2. **Git**：查看改动差异、单文件与批量暂存、Commit 历史、AI 建议生成提交信息与本地提交（无破坏性放弃修改按钮）。
3. **终端**：交互式 xterm 命令行，带移动端专用辅助按键栏（Tab、Esc、Ctrl、方向键），支持优雅关闭终端。
4. **辅助对话**：开辟轻量独立旁聊，支持一键将讨论结论整理并回传给主会话。
5. **服务**：监控本地 Dev Server 后台端口与 PID，支持确认后安全停止。

### 4.7 全局设置与配额看板 (/settings & /quota)
- **设置分类**：严格沿用电脑端 6 大分类原始名称，外观以设计合同为准：
  - 常规（通用、外观、通知、隐私；移除存储空间与快捷键；隐藏电脑独占项）。
  - 模型（模型与供应商、模型角色[保留批量替换]、思考与采样、辅助模型、备用模型与重试、上下文窗口、订阅与配额）。
  - 会话（会话、收件箱、会话体检[只读]、规则文件[查看并编辑]、系统提示词[只读]）。
  - Agent 能力（工具、子代理[可新建+AI帮写+编辑已有]、记忆[编辑笔记，保护技能不被误删]、技能与命令）。
  - 连接（连接与设备[原手机访问改名]、MCP 服务器[查看+添加+编辑]、联网搜索）。
  - 帮助（使用教程、版本与更新[只读]）。
- **订阅与配额看板 (/quota)**：
  - 统一汇总展示所有已配置平台（ChatGPT Plus/Pro、Claude Pro 等）的官方限额看板。
  - 呈现 5 小时与 7 天滚动限额进度条、重置倒计时与绑定账号明细。

## 5. 性能与架构契约

1. **输入框非受控隔离**：文本域不绑定 React 同步受控状态，输入法（IME）合成期间零状态发射、零强制布局重测，4 倍 CPU 降频下按键响应 $\le 0.5\text{ ms}$。
2. **流式 60fps 帧率合批**：高频数据推送收敛至 `requestAnimationFrame` 统一调度刷新。
3. **长对话 40 轮窗口**：DOM 树仅保留尾部 40 轮交互，历史消息按需向上分页，挂载节点数控制在 50 个以内。
4. **重模块按需打包**：Mermaid（~2MB）、xterm 终端独立动态分包，主首屏资源体积 $< 250\text{ KB}$。
5. **后台推送精确防扰**：设备处于前台活跃浏览当前会话时不弹推送；离开会话或切至后台时正常接收 Web Push。

## 6. 验收基准与交付检查

- **自动化检查**：交付时运行并报告全量类型检查、测试和移动端生产构建的实际结果；测试数量随代码变化，不在本 PRD 固定测试文件或用例数，也不预先宣称通过。
- **视觉验收**：以 [`docs/MOBILE_DESIGN.md`](./MOBILE_DESIGN.md) 为准，在 390×844 视口检查首页、抽屉、对话、加号菜单、规划模式、问答表单和配额看板的深浅色表现，确认无水平溢出、无“会话不存在”中断。截图必须对应最终代码；旧截图需注明日期与限制，不能代替最终验收。
- **版本归档**：全部验收通过后，显式暂存任务相关文件并生成英文 Conventional Commit 本地提交；未经授权不推送。验收或所需批准尚未完成时，不暂存、不提交。
