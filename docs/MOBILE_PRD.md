# omp-workspace 移动端重构产品需求文档 (PRD)

---

## 1. 文档概述与背景

### 1.1 项目背景
`omp-workspace` 原有移动端采用简易轻量网页实现，在长时间会话、手机输入法打字、多任务并发和自主代理（Agentic）工作流中存在明显体验短板：
1. **中文输入法（IME）严重掉帧**：输入框高度计算在每次按键触发强制回流，导致拼音选择阶段明显卡顿。
2. **长消息与流式输出性能衰减**：流式生成过程中缺乏稳定的块级缓存，每轮逐字更新均触发整段渲染，长会话下主线程被占满。
3. **会话创建与初次连接脆弱**：新建会话与真实会话进程的交接机制不平滑，曾出现“会话不存在”或首条消息无法派发的边缘情况。
4. **代理工作流缺失**：缺乏子代理（Subagent）监控、规划模式（Plan Mode）闭环、交互式单/多选题澄清、代码变更审查以及富媒体可视化（Mermaid / Visualize）支持。

### 1.2 核心目标
- **框架升级**：基于 React 19 + TypeScript + Vite + Tailwind v4 进行全量重构，由桌面端 Rust 嵌入式 HTTP 服务直接 Host，兼具 Web 的跨设备免安装能力与原生级的毫秒级响应。
- **视觉基准**：严格以 **Gemini iOS** 深色模式真机界面为视觉基线，抛弃传统粗糙的双皮肤方案，还原宇宙微光深黑质感、流线胶囊控件与大圆角卡片系统。
- **交互融合**：深度对齐 **ChatGPT 移动端** 在规划模式、选项式问答澄清、授权审批以及三段式抽屉上的成熟交互模式。
- **功能对齐**：继承桌面端成熟的项目空间拓扑、工作树隔离、多供应商配额看板、辅助对话接回以及划词批注能力。

## 2. 视觉基准与设计原则

1. **界面底色与质感**：纯黑背景（`#000000`）搭配底部极弱宇宙星云深蓝微光渐变，填满安全视口，杜绝假边框、假状态栏与假手机外壳。
2. **严禁竖排文字**：所有标签、徽标、状态与按钮文案一律横排，列宽自适应或单行截断，坚决杜绝“一行一个字”的竖排挤压排版。
3. **触控人体工程学**：所有交互控件满足 iOS HIG 推荐的最低 44pt 触控热区；多步流程支持无损“上一步”回退。
4. **文字可读性承诺**：关键信息（模型名称、工作目录、错误详情、变更代码）均完整可读，不使用无展开手段的单行强制省略截断。

### 3.1 首页 (Home)
- **中性问候**：顶栏居中显示“今天想做点什么？”，彻底移除具体用户名或头像昵称，消除多设备使用时的违和感。
- **移除无用分段**：彻底移除原 Gemini 截图中不适用于编码助理的“聊天／任务”切换分段。
- **轻量会话启动**：
  - 底部提供悬浮胶囊输入框，左侧带加号，右侧带麦克风/发送动态切换按钮。
  - 用户在首页直接键入文字并提交，系统在底层基于默认空间目录快速分配 Draft 会话标识，并直接投递第一轮消息，平滑无感过渡至真实会话页面，杜绝“会话不存在”报错。

### 3.2 全屏导航抽屉 (Left Drawer)
点击首页或会话页左上角汉堡图标，从左侧滑出近全屏的深色导航抽屉：
- **顶部操作组**：
  - **发起新对话**：高亮胶囊按钮，点击可唤起新建会话弹窗（可选择工作空间目录、模型与思考强度）。
  - **搜索会话**：直达会话全文搜索与分支筛选。
  - **定时任务**：直达按计划自动运行的任务列表与排期管理。
- **空间与视图模式切换**：
  - **空间切换**：支持在代码（Code）、日常对话（Chat）、学习、研究等空间维度间切换。
  - **双视图分段器**：提供「按项目」与「按时间」两种浏览方式。
    - **按项目视图**：完整保留桌面端「项目 → 工作树（Worktree） → 会话」的三层折叠树。项目与工作树后方提供加号快捷操作，支持“在当前目录创建”与“在独立工作树创建”。
    - **按时间视图**：将会话按“今天”、“昨天”、“7 天内”、“更早”倒序排列，每项展示运行状态指示点与相对时间。
- **底部常驻条**：
  - **收件箱（铃铛图标）**：带未读红点角标，聚合待审批、待回答、运行中及错误中断项。
  - **订阅与配额**：展示跨供应商的官方限额看板入口。
  - **设置**：通往系统偏好设置中心。
- **冗余剔除**：移除 Gemini 截图中无实际功能的“库”、“学生”、“自定义”、“视频”、“笔记本”等占位行。

### 3.3 对话工作区与输入控制栏 (Chat & Composer)

#### 1. 顶栏规范
- **左侧**：菜单呼出按钮。
- **中偏左**：当前生效的「模型 · 思考强度」胶囊控件，点击从底部弹出两级模型选择器，支持实时切换模型及配套的思考深度（关闭 / 极简 / 低 / 中 / 高 / 极致）。
- **右侧**：一键“新建会话”图标按钮 + 右侧工具箱抽屉按钮。

#### 2. 输入框上方状态条
- **左侧工作目录**：以文件夹图标配简短目录名展示，点击弹出路径详情面板，展示完整绝对路径，支持一键复制路径或切换工作空间。
- **右侧上下文用量**：展示当前会话上下文占比（如 `上下文 32%`），根据水位（正常、预警、临界）显示不同语义色彩；点击呼出上下文抽屉，展示已用 Token、容量上限与“压缩上下文”按钮。

#### 3. 加号菜单（6 大原生选项）
输入框左侧加号弹出底部操作面板，严格对齐桌面端：
1. **文件**：支持调起移动端相册、拍照或系统文件管理器上传附件。
2. **Finder 选中项**：在移动端转换为远程工作区文件选择器，方便将项目代码注入输入框。
3. **在项目中工作**：选择并切换当前会话所挂载的物理工程目录。
4. **目标**：为当前会话设置常驻目标（Goal），并在输入框上方以胶囊徽标展示。
5. **规划模式**：开启后进入任务规划阶段。
6. **草图**：调起全屏手绘白板，绘制架构图或线框草图一键回传。

#### 4. 输入框右侧双按钮
- **语音输入按钮（麦克风）**：
  - 基于移动端浏览器音频采集接口，按住或轻触开启录音，波形动效指示。
  - 录音结束自动投递至后端语音识别接口，利用现有的语音识别模型角色执行高精度转写。
  - 转写文字回填至输入框光标处，用户可自由补充修改后再决定发送，绝不自动代发。
- **发送 / 停止按钮**：
  - 空闲状态下为发送胶囊图标；任务运行中或流式生成中自动切换为方形“停止”按钮，点击可立即中断生成。

### 3.4 代理工作流深度支持

#### 1. 子代理胶囊与全屏详情 (Subagents)
- **浮动胶囊**：挂载于消息区右上角，主会话无派生子任务时完全隐藏；一旦派生出子代理即刻浮现，显示“运行中、排队、完成、失败”各状态统计及总进度分式。会话执行结束后常驻保留完成态。
- **嵌套概览抽屉**：点击胶囊自底向上滑出概览，通过树状连线展示嵌套父子层级（如 `A > B > C`）、每个代理的角色徽标、耗时及状态。
- **全屏详情页**：点击任一子代理进入专属全屏页，分卡片查看完整任务要求、思考折叠、工具调用参数与回包差异、最终产出 Markdown 及错误原因。

#### 2. 规划模式闭环 (Plan Mode)
- **模式触发**：通过加号菜单「规划模式」或直接键入 `/plan` 开启，输入区展示“规划模式已启用”横幅。
- **计划审阅与操作**：
  - AI 生成的结构化规划文本被收纳于规划卡片内，提供复制全文与下载 `.md` 文件操作。
  - 计划底部提供明确的双向决策按钮：
    - **「执行计划」**：向智能体发送确认指令并自动关闭规划模式，进入全自动实施阶段。
    - **「修改计划」**：保持规划模式，自动将输入焦点移至输入框，等待用户补充修正意见。

#### 3. 划词批注 (Text Annotation)
- 用户长按选择对话流中的任意文本（不论是 AI 的回复还是自己的提问），界面弹出批注浮层。
- 浮层提供目标分段器：可选择发送至「主对话」或「辅助对话」。
- 键入补充批注提交后，系统将选中文本作为结构化引用块与批注一并压入对应输入框中，保留系统自带的复制与查询菜单，剔除冗余的收集箱逻辑。

#### 4. 交互式澄清与选项表单 (Questions & Choices)
当 Agent 遇到模棱两可的需求发起澄清询问时：
- 支持渲染单选单选框（Radio）、多选复选框（Checkbox）及“其他（自己填写）”内联文本域。
- 多题并发时展示进度分页器（如 `问题 1 / 3`），支持“上一题”、“跳过”以及提交失败后的“重试”。

#### 5. 工具审批卡片 (Approvals)
- 涉及写文件、运行命令或网络访问等工具调用时，在会话流内就地展示审批卡片，完整呈现命令正文与参数。
- 提供「单次允许」与「本会话记住」授权级别，并支持多工具一键「全部允许」。

### 3.5 富媒体与可视化呈现 (Rich Media & Visualize)

#### 1. Mermaid 图表沙箱渲染
- **未闭合守卫**：流式输出期间检测到未接收完闭合标记的代码块时，维持为纯文本代码展示，杜绝图表引擎频繁报错或重绘抢占主线程。
- **轻量独立加载**：图表解析依赖按需懒加载；输出完成后在隔离的 SVG 容器中呈现。
- **移动端交互**：点击图表或右上角全屏按钮，调起多点触控全屏预览，支持双指平滑放大、缩小（最高 6 倍）与手势拖拽平移。

#### 2. Visualize 交互式沙箱小部件
- **严格沙箱隔离**：使用带严格内容安全策略（CSP）的独立 `<iframe>` 呈现，禁止发起外网未经许可的网络连接，保障本地项目安全。
- **双向数据桥接**：注入宿主环境通信能力，自适应继承移动端深浅色主题，支持状态保存（16KB 内）、超链接外部打开及逆向派发追踪提问。
- **排版保护**：具备高度自适应检测，超宽图表在窄屏下自动堆叠重排，提供源码切换与全屏预览窗口。

---

### 3.6 右侧工具面板集合 (Right Tools)
从顶栏右侧菜单进入，包含 5 项专为手机精简优化的工具页：
1. **文件**：只读浏览工程目录树，带面包屑快速导航，文件内容支持语法高亮与自动换行切换。
2. **Git**：查看工作区未暂存与已暂存改动，单文件与批量暂存，代码差异高亮对比，支持调用 AI 一键生成规范的 Commit Message 并完成本地提交。
3. **终端**：基于 xterm 的交互式命令行，配备触摸专用的辅助按键栏（Tab、Esc、Ctrl、方向键），支持优雅关闭终端进程。
4. **辅助对话**：开辟依附于当前主会话的轻量旁聊流，并支持将旁聊讨论的结论通过“回传给父会话”整理成摘要塞回主会话输入框。
5. **服务**：监控本地正在运行的 Dev Server、长任务等后台端口与 PID，支持查看归属会话并在确认后安全停止。

### 3.7 全局设置与订阅配额 (/settings & /quota)

#### 1. 全局设置结构
采用 Gemini 风格的大圆角分组列表，所有层级严格使用桌面端既有名称：
- **常规**：通用（审批模式、默认模型）、外观（主题、字号、思考预览）、通知（三项状态通知、Web Push 后台推送开关与测试）、隐私（脱敏保护词管理）。
- **模型**：模型与供应商、模型角色（含批量替换功能）、思考与采样、辅助模型、备用模型与重试、上下文窗口、订阅与配额直达。
- **会话**：会话（压缩与排队策略）、收件箱（归档时限）、会话体检（只读监控）、规则文件（`AGENTS.md` 等查看与在线编辑）、系统提示词（只读分析）。
- **Agent 能力**：工具权限、子代理（列表、新建、AI 帮我写、编辑已有定义）、记忆（长期记忆笔记编辑，保护内置技能不被误删）、技能与命令。
- **连接**：连接与设备（显示局域网、隧道与公网地址，一键复制）、MCP 服务器（查看、添加与编辑参数，不开放物理删除）、联网搜索。
- **帮助**：使用教程、版本与更新（只读展示各层组件版本）。

#### 2. 订阅与配额看板 (/quota)
- 统一集成展示所有已配置平台（如 ChatGPT Plus/Pro、Claude Pro 等）的官方限额看板。
- 精确展示 5 小时滚动限额、7 天周期限额的彩色进度条与百分比，清晰展示剩余恢复时间倒计时及关联绑定的账号邮箱。

## 4. 性能指标与工程契约

| 验收维度 | 性能与技术契约 | 实测指标 |
| :--- | :--- | :--- |
| **打字响应耗时** | 输入框绝对非受控，中文拼音合成期零 React 状态派发，零布局回流 | 4 倍 CPU 降频下：p50 $\le 0.1\text{ ms}$，p95 $\le 0.5\text{ ms}$（预算 50ms） |
| **流式帧率合并** | SSE 高频数据流基于 `requestAnimationFrame` 节流合批，上限 60fps | 无论模型生成速度多快，渲染频率恒定且不丢字 |
| **长对话 DOM 控制** | 采用 40 轮滑动窗口机制，历史消息仅在需要时向上分页加载 | 150 轮长对话下挂载 DOM 节点数严格保持在 50 个以内 |
